## 4. 실행

```bash
cd ~/Downloads/폐급재판/pyegeup-app
npx expo start --web       # 웹 (가장 빠름)
npx expo start --android   # 에뮬레이터 (Expo Go 자동 설치)
npx expo start             # QR → 실기기 Expo Go
```

`node_modules`는 설치 완료. 바로 실행됩니다.

- **iOS 시뮬레이터는 이 맥에서 안 됩니다** (Xcode 미설치). 번들 검증만 가능.
- **햅틱(의사봉 진동)은 기기·에뮬레이터에서만** 동작합니다.

### 2026-09-06 (8) — 종이 라이트 전환 · 게시판 밀도 · 사건번호와 도장

**"UI가 너무 AI 느낌"이라는 지적이 두 번째였습니다.** 첫 번째 지적 때는 딥네이비+황동을
무채색 다크로 갈아엎었는데(아래 `2026-09-06 (2)`), 그러고도 티가 남았습니다. 그 사실이 알려준 것은
**문제가 색이 아니라 매체와 문법**이라는 점입니다.

#### 1) 다크 → 종이 라이트

| 근거 | 내용 |
|---|---|
| 읽기 | 이 앱에서 제일 오래 하는 일은 4칸 사연을 읽는 것. 획이 많은 한글은 어두운 배경에서 halation이 라틴보다 심합니다 |
| 은유 | "재판"은 문서의 세계 — 판결문·서류·도장·판례집 |
| 관습 | 한국 커뮤니티는 전부 라이트 기본 (디시·에타·네이트판·더쿠·클리앙) |
| 차별화 | 검정 배경 + 흰 강조 버튼 + 채도 높은 의미색이 **현재 AI 생성 UI의 최빈값** |

순백이 아니라 **미색 종이(`#F4F2EC`) 위에 흰 서류(`#FFFFFF`)** 를 얹습니다.
배경이 순백이면 흰 카드가 녹아 층이 사라지고, 전부 미색이면 서류가 뜨지 않습니다.

**다크는 버리지 않고 개표 3초에만 남겼습니다** (`theme.dark` + `app/case/result.js`).
밝게 읽다가 불이 꺼지고, 확정과 함께 조명이 올라옵니다(0.56초 색 보간).
처음부터 어두우면 게이지 역전 연출이 배경에 묻힙니다.

**라이트로 오면서 제약 하나가 사라졌습니다.** 다크에서는 빨강이 둘이어야 했습니다 —
글자용은 밝고(`#FF4D57`) 채움용은 어두워야(`#DC2029`) 해서 요구가 정반대였습니다.
종이 위에서는 인주 빨강 `#B3271B` 하나가 글자로도 채움으로도 6.52:1로 통과합니다.
`brand`/`brandFill`은 호환을 위해 남기되 값이 같습니다. **`dark`에서는 여전히 둘입니다.**

**대비 기준이 하나 늘었습니다.** 라이트에서 가장 까다로운 배경은 `bg`가 아니라
`surfaceAlt`(`#EBE8E0`)입니다 — 칩·빈 상태·입력 배경이 이 색입니다.
`textFaint`(4.66)와 `ticket`(4.51)이 간당간당하니 밝히지 마세요.

#### 2) 목록: 카드 → 행

가장 큰 레이아웃 변경입니다. 사건 하나가 `rounded 12 / border 1 / padding 15` 박스에
제목 + 쟁점 2줄 + 아이콘 메타를 담아, **390px 화면에 사건이 2.5개** 들어갔습니다.
디시·클리앙·에타는 한 화면에 12~15줄이 뜨고 그 밀도가 훑어보는 재미의 전부입니다.

```
 1 │ [직장] 팀 회식 중간에 말없이 집에 갔습니다              🔖
   │ 2026고합1174 · 1,240표 [96]            3시간 3분
```

- `CaseList`(흰 서류판) + `CaseCard`(행). 제목 1줄 · 메타 1줄 **고정**
- 좌측 열 = "이 행의 신분": 데일리는 순번(디시의 글번호 열), 판례집은 확정 도장
- 아이콘 메타(사람·문서·자물쇠) → `1,240표 [96]`. 대괄호 댓글수는 한국 게시판 관습

> **메타 줄이 한 번 접히면 밀도가 통째로 무너집니다.** 처음엔 접혀서 행 높이가 두 배가
> 됐는데, `numberOfLines={1}`만으로는 부족하고 `flexShrink: 0`을 **같이** 걸어야 합니다.
