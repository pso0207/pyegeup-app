# 홈 개편 · 2026-09-07

## 피드백과 판단

사용자가 제공한 화면에서 큰 활동 카드, 일정 카드, 검정 투고 배너가 연속으로 나타났다.
`님이 …했습니다`라는 활동 알림과 고정된 상대 시간이 반복되어 샘플 대시보드처럼 느껴진다는 피드백이다.
색이나 둥글기만 바꾸기보다 읽을 사연을 먼저 보여주는 구조로 개편했다.

## 확인한 레퍼런스

- [다모앙 자유게시판](https://damoang.net/free): 공지를 목록 위에 짧게 배치하고 제목·작성자·반응 정보를 함께 제공한다. 홈 안내 행에 반영.
- [Hacker News](https://news.ycombinator.com/): 제목과 작성자·댓글 등 보조 정보의 분리가 명확하다. 홈 사건 행의 정보 위계에 반영.
- [Discourse Meta](https://meta.discourse.org/latest): 주제 목록에 답글과 활동 정보를 제공하고 목록을 탐색한다. 오늘/토론 많은/판결 완료 전환에 반영.
- [Reddit AmItheAsshole](https://www.reddit.com/r/AmItheAsshole/): 개인의 사연을 읽고 판단하는 커뮤니티라는 콘텐츠 구조를 참고했다. 타 사이트의 사연이나 댓글은 복사하지 않았다.
- 클리앙은 접근 제한으로 본문 확인이 불가능해 검증된 근거로 사용하지 않았다.

위 내용은 접근 가능한 페이지의 정보 구조를 바탕으로 한 디자인 해석이다. 모든 사이트를 조사하거나 시각적으로 비교한 것은 아니다.

## 구현

- 홈도 다른 탭과 같은 미색 종이 바탕을 사용한다. 제목·작성자·참여 수·의견 수를 괘선으로 이어 읽는다.
- 오늘의 재판 / 의견 수 내림차순 / 종결 사건 탭을 실제 데이터에 연결.
- 홈 제목은 두 줄까지 허용한다. 기존 다른 화면의 한 줄 CaseCard 규칙은 유지한다.
- 삭제·차단한 사건은 홈에서도 제외하고, 참여 여부는 저장된 상태를 사용한다.
- 큰 데일리 박스는 참여 건수와 다음 사건 링크로 축소.
- 자동 속보, 자동 증가 표 수, 고정 실시간 활동 카드, 일정 카드, 큰 하단 투고 배너를 홈에서 제거.
- 글쓰기는 목록 제목 옆 40px 이상 버튼으로 제공한다.
- 온보딩 진입은 상단 안내 행에 연결하고 안내 화면에 돌아가기 버튼을 추가했다. 법원 선택 초기값은 현재 소속을 사용한다.
- 판결 전 의견 본문이나 투표 비율을 홈에 노출하지 않는다.

현재 데이터는 기존 목업이다. 이번 변경이 실시간 서비스나 백엔드를 추가하지는 않는다.
공통 색·글꼴 토큰, 다른 탭과 사건 상세 화면은 유지한다.

### 겹침 보정

- 홈 배경을 다른 탭과 같은 미색으로 통일했다.
- 320px대 화면에서 헤더·안내·진행 현황이 서로 밀지 않도록 유연 폭과 한 줄 제한을 적용했다.
- 탭 3개는 남는 폭을 똑같이 나눠 글자 확대 시에도 겹치지 않게 했다.
- 오늘 목록과 다시 겹치던 초박빙 추천 구역을 제거했다.
- 상·하단에 중복되던 글쓰기와 이용 안내는 상단에 한 번씩만 남겼다.
- 공통 화면 헤더와 법원 대항전 행에도 긴 제목 축소 규칙을 적용했다.
