# 도메인 규칙

수치의 **출처는 `constants/domain.js`** 입니다. 이 문서는 읽기용 사본이니,
값을 바꿀 땐 코드를 고치고 여기를 따라 고치세요.

## 형량 5단계

| 단계 | 이름 | 뉘앙스 | 햅틱 |
|---|---|---|---|
| 1 | 훈방 | 그럴 수도 있지 | Light |
| 2 | 벌금형 | 좀 잘못했네 | Light |
| 3 | 집행유예 | 확실히 잘못 | Medium |
| 4 | 실형 | 많이 심함 | Heavy |
| 5 | 무기징역 | 인간이 아님 | Heavy ×3 (90ms 간격) |

## 판사 지수 (올라가는 축)

| 계급 | 구간 | 비고 |
|---|---|---|
| 방청객 | 0 – 199 | |
| 예비배심원 | 200 – 599 | |
| 배심원 | 600 – 1,499 | |
| 배심원장 | 1,500 – 2,999 | |
| 판사 | 3,000 – 5,499 | 상위 20% |
| 부장판사 | 5,500 – 8,999 | 상위 5% |

계급 문자열을 목업에 직접 쓰지 말고 **항상 점수에서 파생**시키세요.
`JUROR_TIERS`에 없는 이름을 넣으면 진행바 계산이 조용히 틀어집니다
(`대법원장`이 그래서 한 번 사고를 냈습니다).

## 폐급 지수 (내려가는 축)

| 계급 | 구간 | 설명 |
|---|---|---|
| 성인군자 | 0 – 14 | 심판대에 섰으나 흠 없이 내려옴 |
| 모범시민 | 15 – 29 | 대체로 무죄 |
| 경고누적 | 30 – 44 | 애매한 인간 |
| 집행유예 | 45 – 54 | 반반의 갈림길 |
| 전과자 | 55 – 69 | 유죄가 더 많음 |
| 상습범 | 70 – 84 | 반복적으로 유죄 |
| 폐급 | 85 – 94 | 만장일치급 |
| 인간말종 | 95 – 100 | 명예의 전당 (본인만 열람) |

사건 3건 이상 누적 시 계급 부여. 계급 변동은 사건 확정 시점에만 반영.
**남에게는 숫자를 공개하지 않고 계급만** 보입니다 (기획서 13 결정사항).

## 교차 칭호

| 조건 | 칭호 |
|---|---|
| 폐급 < 55, 판사 ≥ 3000 | 청렴결백 |
| 폐급 < 55, 판사 < 3000 | 평범한 시민 |
| 폐급 ≥ 55, 판사 ≥ 3000 | 내로남불 |
| 폐급 ≥ 55, 판사 < 3000 | 구제불능 |
| 폐급 ≥ 85, 판사 ≥ 9000 | 타락한 재판관 |

카테고리 적중률 75% 이상 + 30건 이상이면 부칭호 (예: `연애 전문 판사 79%`).

## 판사 지수 획득

| 항목 | 값 |
|---|---|
| 다수의견 적중 | +10 |
| 형량 정밀 (평균과 차이 1 이내) | +5 |
| 선구안 (마감 전 50% 이내 투표 후 적중) | ×1.5 |
| 초박빙 사건 적중 (유죄율 45–55%) | +20 |
| 만장일치 사건 적중 | +2 |
| 판결문 추천 획득 | +3 |
| 데일리 5건 완주 | +15 |
| 7일 연속 출석 | +50 |
| 오답 | 감점 없음 |

콤보 배수: 3연속 ×1.2 · 5연속 ×1.5 · 10연속 ×2.0
**콤보는 "연속 적중"입니다** — 오답이면 0으로 초기화됩니다.
("오답 감점 없음"은 점수를 깎지 않는다는 뜻이지, 배수를 유지한다는 뜻이 아닙니다.)

### 일일 한도 (`store.claims`)

| 항목 | 한도 |
|---|---|
| 데일리 출석 | 1일 1회 · +10 |
| 리워드 광고 | 1일 3회 · 회당 +5 |
| 법원 이적 | 시즌당 1회 (`transfersUsed`) |

09:00 회차(`courtDay()`)가 바뀌면 초기화됩니다.
**화면에 "1일 N회"라고 쓸 거면 여기에도 넣으세요.** 문구만 쓰면 지켜지지 않습니다.
시즌 종료 시 소프트 리셋 — 점수 40%만 이월.

## 티켓

**소모** — 판결 1 · 조기 열람 3 · 항소 50
**획득** — 데일리 출석 10 · 7일 연속 20 · 사연 승인 25 · 광고 5(1일 3회) ·
판결 랜덤보상 기대값 1.5 · 대항전 1위 100

랜덤보상 확률: 일반 88% (티켓 1) · 황금 10% (5) · 다이아 2% (20)

## 법원 6종

연애지법 · 직장지법 · 가족지법 · 우정지법 · 금전지법 · 온라인지법

사건 분류이자 길드. 주간 대항전은 **인원수 보정 평균 판사 지수** 기준,
1위 법원 소속원 전원 티켓 100장. 이적은 시즌당 1회.

## 사건 상태

`review` 검수대기 · `open` 공판중 · `counting` 개표 · `closed` 확정 ·
`statement` 최후진술 · `appeal` 항소중 · `void` 무효(20표 미달)

## 데일리 회차

매일 **09:00**에 새 5건 배정. 09:00 이전은 아직 어제 회차로 셉니다
(`courtDay()` 참고). 공판 기간은 24시간.
